# Transformers, NLP & Vision Architectures

> **Structural Depth:** Depth $d=2$ | **Parent:** Track 3 AI Landscape

### Core Mental Models
1. **Self-Attention:** Tokens query all other tokens in parallel.
2. **KV Caching:** In autoregressive decoding, past Key and Value matrices are cached to prevent recomputing previous token representations.
3. **Subword Tokenization:** Byte-Pair Encoding (BPE) balances vocabulary size with token coverage.
