# Classical Machine Learning & Modeling

> **Structural Depth:** Depth $d=2$ | **Parent:** Track 3 AI Landscape

### Core Mental Models
1. **Bias-Variance Trade-off:** High bias = underfitting; high variance = overfitting. Cross-validation guides optimal complexity.
2. **Gradient Boosted Decision Trees:** Sequentially fitting trees to the pseudo-residuals of previous trees.
3. **Metric Alignment:** Precision (low false positives) vs Recall (low false negatives) vs ROC-AUC.
