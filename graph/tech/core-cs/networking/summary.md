# Computer Networking & Protocols

> **Structural Depth:** Depth $d=2$ | **Parent:** Track 0 Core CS

### Core Mental Models
1. **OSI vs TCP/IP:** Layer 4 Transport (TCP, UDP) vs Layer 7 Application (HTTP, DNS, gRPC).
2. **Head-of-Line Blocking:** HTTP/1.1 pipelining block $\to$ HTTP/2 TCP packet block $\to$ HTTP/3 QUIC (UDP) independent streams.
3. **TLS 1.3 Zero-RTT:** Resumption handshakes reduce initial latency by a full round-trip time.
