## The 4 Parallel Tracks

1. **Track 0: Core CS Foundations (`core-cs`):** Algorithmic complexity, OS concurrency, networking protocols, craftsmanship.
2. **Track 1: Software Engineering (`swe`):** High-throughput APIs (FastAPI/Go), PostgreSQL optimization, Docker, system design.
3. **Track 2: Data Ecosystem (`data`):** Advanced SQL analytics, dbt transformations, Airflow orchestration, Spark big data.
4. **Track 3: AI Landscape (`ai`):** Classical ML, PyTorch architectures, Transformers, enterprise RAG, and MLOps.
5. **Milestone Fusion Projects (`fusion`):** Production repositories combining backend services, data pipelines, and AI inference.
