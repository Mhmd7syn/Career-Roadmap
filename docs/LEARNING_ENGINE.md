# Learning Engine

## The 3-Pass Loop
1. **Pass 1: Concept Intake**
   - Concise, focused explanations (flexible duration; prioritize clarity over length).
   - Flexible sources: YouTube, DeepLearning.AI, Coursera lectures, official docs, interactive tutorials, or any high-quality web resource.
2. **Pass 2: Active Recall**
   - Graded quizzes, coding labs, and drills (Coursera, LeetCode/NeetCode, roadmap.sh checkpoints).
3. **Pass 3: Production Synthesis**
   - 1 production-style GitHub repo per major topic cluster (tested with `pytest`, containerized, documented).
