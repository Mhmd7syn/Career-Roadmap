# Continuous Fusion Projects

## Milestone 1: Triad Microservice
- **SWE:** FastAPI backend + PostgreSQL + Docker.
- **Data:** SQL ingestion pipeline + metrics computation.
- **AI:** Integrated ML prediction or open-weights model inference endpoint.
- **Output:** Test-backed GitHub repository (`pytest`, Docker).

## Milestone 2: Intelligent Data Application
- **SWE:** Async task queue (Celery/Redis) + JWT auth + rate limiting.
- **Data:** Orchestrated ETL (Airflow/Prefect) feeding warehouse/lakehouse + data tests.
- **AI:** RAG pipeline over warehouse data with vector search.
- **Output:** Multi-container operational service.

## Milestone 3: Real-Time AI Streaming System
- **SWE:** gRPC/WebSocket API + Prometheus/Grafana observability.
- **Data:** Kafka/Redpanda event streaming + Spark processing.
- **AI:** vLLM/Triton inference serving + Langfuse tracing & eval metrics.
- **Output:** Production portfolio capstone.
