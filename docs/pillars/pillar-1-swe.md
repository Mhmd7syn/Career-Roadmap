# Pillar 1: Software Engineering (SWE)

## Breadth Survey Scope
- **Languages:** Python (advanced), Go or TypeScript basics.
- **Web APIs:** REST, gRPC, WebSockets, auth (OAuth2/JWT).
- **Databases:** PostgreSQL (indexing, ACID, migrations), Redis caching, MongoDB/DynamoDB overview.
- **DevOps & Containers:** Linux CLI, Docker, Docker Compose, basic cloud compute/storage.
- **CI/CD & Testing:** GitHub Actions, `pytest`, pre-commit hooks, linting/formatting.
- **System Design:** Caching, load balancing, stateless vs stateful, monolith vs microservices.

## Candidate Deep Dives
- Distributed systems & concurrency.
- Cloud architecture & Kubernetes.
- High-scale API platforms.
