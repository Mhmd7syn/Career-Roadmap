# Pillar 2: Data Ecosystem

## Breadth Survey Scope
- **Analytics & BI:** Pandas, Polars, KPI metrics, Metabase/Tableau.
- **Data Modeling:** Advanced SQL (CTEs, Window functions), Star/Snowflake schemas, Parquet.
- **Warehousing:** Snowflake or BigQuery basics, `dbt` modeling and tests.
- **Pipelines:** ETL vs ELT, Apache Airflow or Prefect (DAGs, retries, backfills).
- **Big Data:** Apache Spark / PySpark core, Kafka / Redpanda streaming overview.
- **Data Quality:** Great Expectations, schema drift checks.
- **Data Science:** Statistical testing, feature engineering pipelines, baseline models.

## Candidate Deep Dives
- Modern Lakehouse (Apache Iceberg, Delta Lake).
- Real-time streaming systems.
- Analytics engineering & causal decision science.
