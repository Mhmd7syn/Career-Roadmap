# Core CS Foundations: Computer Science & Systems

> **Priority #1 Roadmap to Build & Execute**

## Core Modules
- **Data Structures & Algorithms:** Arrays, hashes, trees, graphs, heaps, time/space complexity ($O(n)$), core problem patterns.
- **Operating Systems & Systems Programming:** Processes, threads, concurrency, memory models, Linux CLI, bash, file descriptors.
- **Computer Networking:** TCP/IP stack, HTTP/HTTPS (1.1, 2, 3), DNS, TLS/SSL, WebSockets, sockets.
- **Software Craftsmanship:** Git workflows (rebase, bisect, squash), Clean Code, design patterns, unit testing methodology.
- **Computer Architecture Basics:** CPU caches, I/O bottlenecks, storage tiers (RAM vs SSD vs Disk).
