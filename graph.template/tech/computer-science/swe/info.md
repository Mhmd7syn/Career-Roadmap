# SWE

**Status:** todo

Foundations of software engineering: client-server architecture, baseline REST API mechanics, elementary persistence, and local containerization.

## Learning Outcomes
- Understand the client-server architecture, HTTP request/response lifecycles, methods, and status codes.
- Implement a basic RESTful API endpoint returning structured JSON payloads.
- Connect an application service to a local database to perform baseline CRUD operations.
- Write a simple Dockerfile to package a minimal web application into a runnable local container.
