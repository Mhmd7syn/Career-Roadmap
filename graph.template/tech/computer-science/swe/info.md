# SWE

**Status:** todo

Production software engineering focusing on scalable backend services, API contract design, relational databases, containerization, and distributed systems.

## Learning Outcomes
- Build high-throughput asynchronous backend services and APIs using modern frameworks (FastAPI, Go, Node.js).
- Design relational database schemas, query indexing strategies (B-Tree, Hash, GIN), connection pools, and caching layers (Redis).
- Containerize multi-tier applications using Docker multi-stage builds and Docker Compose.
- Apply distributed system design fundamentals: load balancing, rate limiting, circuit breakers, idempotency, and the CAP theorem.
- Implement comprehensive automated testing suites (unit, integration, regression) and CI/CD workflows.
