# Teaching & Mentoring

**Status:** todo

Foundations of technical mentorship and pedagogy: breaking down complex concepts, active listening, and conducting constructive code reviews.

## Learning Outcomes
- Apply the Feynman Technique to explain a technical concept in plain, jargon-free terminology.
- Structure a productive 30-minute 1-on-1 coaching session centered on diagnosing learner bottlenecks.
- Write constructive, empathetic code review comments that clarify the rationale behind improvements.
- Use diagnostic questioning to guide learners toward self-discovery instead of prematurely giving solutions.
