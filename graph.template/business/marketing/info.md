# Marketing

**Status:** todo

Foundations of technical communication and inbound visibility: articulating project value, learning in public, and crafting clear technical write-ups.

## Learning Outcomes
- Understand the compounding leverage of public documentation and technical storytelling.
- Structure an informative, reproducible project README with clear installation steps and live demos.
- Set up a minimal personal platform (GitHub profile, technical blog, or LinkedIn presence).
- Translate a completed coding experiment into a concise, readable breakdown for peers.

## Checkpoint
- [ ] Does your primary open-source repo or portfolio project have a clear 1-paragraph elevator pitch and demo?
- [ ] Can you explain the core philosophy behind "Learn in Public"?
- [ ] Can you take a bug or bugfix you recently solved and summarize it in a 3-bullet post?
