# Knowledge Graph

**Status:** in-progress

Foundational launchpad for self-directed learning: core cognitive principles that make study effective, and external roadmap resources for navigating new domains.

## Learning Outcomes
- Apply core cognitive learning models: focused vs. diffuse thinking, retrieval practice, and spaced repetition.
- Use the Pomodoro technique and process-over-product mindset to overcome procrastination.

## Checkpoint
- [ ] What is the difference between active recall (retrieval practice) and passive re-reading?
- [ ] What makes spaced repetition more effective than massed practice for long-term retention?

## Lab / Project Target
- **Pomodoro & Active Recall Session:** Complete a 25-minute focused study block on any topic in the graph, then do a retrieval practice pass from memory. Log observations in `notes.md`.
