## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please report it responsibly rather than opening a public issue.

To report a vulnerability:
1. Privately disclose the vulnerability by contacting the maintainer via GitHub Security Advisories or direct message.
2. Please provide:
   - A description of the issue and potential impact.
   - Minimal steps or proof-of-concept to reproduce the vulnerability.
   - Any suggested remediations or mitigations.

You will receive an acknowledgment of your report within 48 hours, followed by updates on progress toward a patch.
